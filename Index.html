Welcome — Manager Dashboard
Follow these steps each morning to get your pickers started
1️⃣
Load Pick List
Click Load pick list tab → drag and drop your Orders.xlsx → app reads both sheets and loads all orders. All tablets receive orders automatically via sync.
2️⃣
Pickers Start
Pickers click Picker → sign in with name → tap an order from the list → confirm each pick line with qty and lot number.
3️⃣
Monitor Progress
Dashboard updates live as pickers work. 🟢 Green = complete  🔵 Blue = in progress  🔴 Red = not started. Click View on any order to see details.
4️⃣
Print Invoices
Click 📄 Invoice next to any order → delivery note opens → click Print / Save PDF to print or save.
5️⃣
Export to AccountMate
Click AccountMate export tab → download CSV per order → import directly into AccountMate. Or download all as ZIP.
6️⃣
View Picking Stats
Click Picking stats tab → see performance by picker, daily totals, units picked, replacement lots. Export as CSV for records.

Daily workflow — no Claude needed

  1. Each morning, export your orders from your system as usual — keep it as .xlsx
  2. Make sure the file has two sheets: "open sale order" (orders) and "Items availabe" (stock & lots)
  3. Click the upload area below or drag and drop the file
  4. The app reads both sheets, matches items to lot numbers, and loads all orders automatically
  5. All pickers see the updated orders immediately — no CSV, no Claude, no copy-paste
Tip: Save this app to a shared network drive or Google Drive. Everyone opens the same file. You upload once in the morning — done.
